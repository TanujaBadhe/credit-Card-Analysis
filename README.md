# 💳 Credit Card Analytics Dashboard

## 📊 Project Overview

The **Credit Card Analytics Dashboard** is a data analytics project designed to analyze credit card transactions and customer behavior.

The project focuses on understanding **revenue, transaction volume, customer spending patterns, card usage, payment behavior, and customer segmentation** through an interactive Power BI dashboard.

The project demonstrates an end-to-end analytics workflow, including **data cleaning, transformation, analysis, KPI development, and dashboard creation**.

## 🎯 Objectives

* Analyze overall credit card transaction performance.
* Track revenue and transaction trends.
* Understand customer spending behavior.
* Analyze transaction patterns by card type.
* Identify high-value customer segments.
* Analyze transaction methods and categories.
* Monitor key business KPIs through an interactive dashboard.

## 📁 Dataset

The dataset contains credit card transaction and customer-related information such as:

* Customer ID
* Transaction ID
* Transaction Date
* Card Type
* Transaction Amount
* Transaction Category
* Transaction Method
* Customer Demographics
* Location
* Revenue-related metrics

## 🔄 Project Workflow

### 1. Data Preparation

Imported the credit card dataset into Excel and Power BI for analysis.

### 2. Data Cleaning

Used **Excel and Power Query** to:

* Remove duplicate records
* Handle missing values
* Correct data types
* Standardize categorical values
* Transform date fields
* Create calculated columns
* Prepare data for dashboard development

### 3. Data Analysis

Analyzed:

* Total revenue
* Total transactions
* Transaction volume
* Average transaction value
* Card-type performance
* Customer spending behavior
* Transaction categories
* Payment methods
* Monthly and yearly trends

### 4. Dashboard Development

Built an interactive **Power BI dashboard** containing:

* KPI cards
* Revenue trends
* Transaction trends
* Card-type analysis
* Customer segmentation
* Transaction-category analysis
* Payment-method analysis
* Interactive slicers
* Drill-down analysis

## 📈 Key Dashboard Metrics

| KPI                       | Description                          |
| ------------------------- | ------------------------------------ |
| Total Revenue             | Total revenue generated              |
| Total Transactions        | Total number of transactions         |
| Total Customers           | Number of customers                  |
| Average Transaction Value | Average value per transaction        |
| Total Amount              | Total transaction amount             |
| Active Customers          | Customers with recorded transactions |

## 💡 Key Insights

The dashboard helps identify:

* Monthly and yearly transaction trends.
* High-performing card types.
* Customer spending patterns.
* Popular transaction categories.
* High-value customer segments.
* Changes in transaction volume over time.
